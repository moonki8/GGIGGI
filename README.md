# GGIGGI — 매일 아침 주식 시장 브리핑

매일 한국시간(KST) 오전 9시에 한국(코스피/코스닥)과 미국(S&P500/나스닥/다우) 시장 현황을
거시경제 관점에서 요약해주는 자동 브리핑 루틴입니다.

## 동작 방식

- Claude Code Remote의 스케줄 트리거(cron `0 0 * * *`, UTC 기준 = KST 09:00)가
  매일 이 세션으로 브리핑 요청 프롬프트를 전달합니다.
- 트리거가 실행되면 다음 정보를 조사해 하나의 브리핑으로 정리합니다.
  1. 미국 시장 마감 동향 (지수 등락, 연준/금리 이슈, 주요 실적)
  2. 한국 시장 개장 전후 동향 (선물 지표, 원/달러 환율, 간밤 이슈의 영향)
  3. 거시 환경 (금리, 환율, 원자재, 경제지표 일정, 지정학 이슈)
  4. 종합: 단순 시세 나열이 아니라, 위 정보를 바탕으로 오늘 주목할 만한
     섹터·테마·자산군과 그 거시적 근거를 제시

## 트리거 관리

- 트리거 이름: `매일 아침 주식시장 브리핑`
- 실행 시각을 바꾸거나 중단하려면 Claude Code Remote의 트리거 목록에서
  해당 트리거를 수정/삭제하면 됩니다.
